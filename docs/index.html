Algebraic quote deltas & TigerStyle invariants.

In prediction-market orderbooks, duplicate WebSocket frames and rapid oracle wiggles cause naive bots to double-place or 429-ban themselves. seiche enforces six algebraic delta identities across 2,020 exhaustive state-transition combinations (`seiche prove --json`). 

// Packed (height: u16, node_id: u32) -> single u64 CPU comparison (Guarantee S3)
impl HeapEntry {
    pub const fn pack(height: u16, node_id: u32) -> u64 {
        ((height as u64) << 32) | (node_id as u64)
    }
}

// Exact integer Kalshi quadratic taker fee in centicents ($1.00 = 10_000 cc)
pub const fn kalshi_taker_fee_cc(qty_h: i64, price_cc: i64) -> i64 {
    let num = 7i128 * (qty_h as i128) * (price_cc as i128)
              * ((10_000 - price_cc) as i128);
    ((num + 50_000_000) / 100_000_000) as i64
}
